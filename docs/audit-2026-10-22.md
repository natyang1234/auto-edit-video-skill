#### A2.（中）第 37 行以 `$auto-edit-video` 作為呼叫範例，這是 Codex 語法；Claude Code 的呼叫語法是 `/auto-edit-video`

- 檔案／行號：`skills/auto-edit-video/SKILL.md` 第 34–38 行。

  副註：這個 `$auto-edit-video` **不會**被 Claude Code 的引數替換誤處理。D1「Available string substitutions」只替換 `$ARGUMENTS`、`$ARGUMENTS[N]`、`$N`，以及 frontmatter `arguments:` 宣告過的 `$name`；本 skill 沒宣告 `arguments`，所以 `$auto-edit-video` 與本文多處的 `$SKILL` 都會原樣保留。
- 依據：D1、D2。
- 建議改法：把範例改成不綁特定代理的寫法，例如「Use the auto-edit-video skill to …」，或在同一段並列「Claude Code: `/auto-edit-video …`；Codex: `$auto-edit-video …`」。若日後要在 frontmatter 加 `arguments:`，不要用 `SKILL` 當引數名，否則本文的 `$SKILL` 會被替換。
- 驗證：

  ```text
  $ python3 -（掃描本文所有 $token）
  dollar tokens in body: ['$SKILL', '$auto-edit-video']
  ```
