# Agent-first 自動剪輯規格（第一階段）

## 1. 目標

第一階段只處理一件事：讓已安裝本 Skill 的本機 AI Agent 讀取使用者提供的影片檔，自行完成剪輯並輸出新的 MP4。

這一階段不需要操作介面、預覽網站、LINE 傳送、社群平台發佈或任何私人傳送路徑。

## 2. 使用者契約

使用者唯一必須提供的資料是本機影片檔。剪輯方向可用自然語言補充，但不是必填的設定表單。

範例：

```text
請用 auto-edit-video 自動剪輯 ./input.mp4
```

```text
請把 ./input.mp4 剪成約 30 秒精華
```

Agent 必須自行處理工作目錄、轉錄、剪輯決策、輸出與 QA，不應先要求使用者另外準備 Whisper JSON、SRT、manifest 或頁面設定。

## 3. 輸入與輸出

| 項目 | 規格 |
|---|---|
| 必填輸入 | 一個 Agent 有權讀取的本機影片檔 |
| 支援格式 | 任何本機 FFmpeg/ffprobe 能正常解碼的影片格式 |
| 選填指示 | 目標長度、語言、直式／橫式、是否保留完整內容等自然語言要求 |
| 主要輸出 | 一個新的可播放 MP4；原始影片不可被覆寫 |
| 內部產物 | Agent 可建立轉錄、剪輯決策、cut map 與 QA 檔，但不得要求使用者手動提供 |

若使用者沒有指定長度，預設做保守的全長清理，不可任意截成 30 秒。只有使用者明示「約 30 秒精華」時，才以約 25–35 秒為工作目標，並優先保留語意完整的段落。

## 4. Agent 執行流程

1. 解析並驗證影片路徑；確認檔案可讀、不是目錄，而且 ffprobe 能找到有效視訊串流。
2. 執行 `auto_edit.py preflight`；`ready: false` 或 `missing_required` 非空時停止並回報真正缺少的依賴。
3. 自動建立獨立工作專案；複製或連結原始素材，但不得修改原檔。
4. 優先使用本機 Whisper 相容引擎產生含單字時間碼的轉錄。Agent 自行建立 JSON/SRT；預設不得上傳原始音訊或逐字稿。
5. 匯入轉錄並分開分析停頓、贅字、口吃、重複與說錯重講。
6. 低風險候選可依保守規則自動決定；高風險候選一律保留，除非使用者的自然語言指示已明確涵蓋該刪除。
7. 將使用者本回合的「自動剪輯」要求記錄為低風險剪輯授權，再用 `render_cut.py` 產生新的 MP4。
8. 剪完後重新檢查成品時長、音訊／視訊串流與可播放性；需要字幕或語意核對時，必須重新轉錄剪切後的影片。
9. 執行 `qa_video.py`。只有 QA 未出現阻斷錯誤時，才向使用者回報剪輯完成與成品位置。

## 5. 自動決策規則

Agent 可自動處理的低風險項目：

- 明確、過長而不具修辭作用的停頓；
- 單獨出現且沒有語意的贅字；
- 緊鄰、短促，且後一次完整包含前一次內容的口吃；
- 使用者已明示要取用的完整連續片段之外的內容。

Agent 不可自行刪除的高風險項目：

- 包含人名、數字、單位、否定詞、條件或例外的句子；
- 兩句看似重複但主詞、數字或結論不同的內容；
- 技術名詞重講、完整句子或敘事順序變更；
- 任何可能改變原始主張的片段。

共同規則：刪除較早的失敗嘗試，保留後面完整說法；不確定時保留；不可切斷字尾或音節。

## 6. 約 30 秒精華規格

只有在使用者提出短影音或約 30 秒需求時套用：

- 目標長度：25–35 秒；內容完整性優先於精確 30.000 秒。
- 優先選擇能獨立理解、具有明確開頭與結論的連續內容。
- 不得只依音量或講話密度宣稱找到「最佳精華」；Agent 必須根據本機轉錄判斷語意。
- 若沒有任何 25–35 秒片段能保持主張完整，應輸出最短的完整版本並說明實際時長。
- 字幕、標題與動畫不是第一階段必填輸出；使用者要求時才啟用進階流程。

## 7. 完成條件

Agent 只有在下列條件成立時才能回報完成：

- 原始影片仍存在且未被修改；
- 新 MP4 存在、大小大於零，ffprobe 能讀到有效時長與視訊串流；
- 原片有音訊時，成品也有音訊，除非使用者明示靜音；
- 所有實際刪除範圍都有可追溯的決策或使用者指示；
- `qa_video.py` 沒有回傳阻斷狀態；
- Agent 回報實際成品，而不是只回報計畫、manifest 或預覽網址。

## 8. 第一階段不做的事

- 不要求或啟動網頁操作介面；倉庫內既有頁面編輯器屬選配，不是本階段完成條件。
- 不傳送到 LINE、Email、雲端硬碟或社群平台。
- 不把影片、音訊或逐字稿上傳到臨時公開服務。
- 不自動使用雲端 TTS、聲音複製、外部 B-roll 或未授權素材。
- 不使用 CapCut，也不修改 CapCut 草稿。

## 9. 執行環境

Agent 必須能存取本機檔案系統並執行 Python、ffmpeg 與 ffprobe。完整語意剪輯另需本機 Whisper 相容轉錄引擎；缺少轉錄引擎時，Agent 應誠實回報只能做機械式停頓清理，不得假裝已完成語意精華選段。

純瀏覽器聊天介面若不能讀取本機檔案或執行命令，即使看得到 `SKILL.md`，也不能執行這個流程。

## 10. 下一階段

頁面預覽、拖拉時間軸、字幕樣式、標題卡、動畫、封面與平台尺寸控制列入下一階段。這些功能可沿用倉庫內既有元件，但不得阻擋本階段的 Agent-first 影片輸入與 MP4 輸出。
