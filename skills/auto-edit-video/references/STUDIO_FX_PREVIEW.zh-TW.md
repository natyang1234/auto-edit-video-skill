# 在自己的影片上試看風格

1. 匯入影片後，按「試看本片特效」或新增特效圖層。
2. 選擇風格、原片起點與試看長度，再調整文字、擺位、色組和字型。
3. 等待短片生成並播放檢查，按「套用到時間軸」才會新增或替換圖層；取消試看不會套用候選設定。

卡片是風格示意圖。選取後的播放器才是用目前專案原片產生的動態結果。首次生成需要本機渲染，相同來源與設定可重用快取；快速切換設定會取消舊工作。

## 範圍

- 168 種風格中有 167 種可用此流程。B1 需要另選 B-roll 素材，本版會明確提示並阻止試看。
- 每次試看 0.1–4 秒，使用原片時間軸與 9:16 畫布。原片可以是橫向影片，構圖沿用專案的完整顯示或填滿設定。
- 試看包含原片及單一特效。其他時間軸圖層、字幕、剪輯與整體影片模板請用「輸出預覽」檢查。
- 人物合成與 P5 聚光燈需要本片的有效人物遮罩；找不到清楚人物時會提示換片段，不會以示範人物代替。小、暗或不完整的人物可能被拒絕；燒在原片裡的字幕也可能影響去背。
- 替換超過 4 秒的既有圖層時，視窗會明示新範圍；確認後會採用這個較短的範圍。
- 短預覽與整片輸出不能在同一專案同時執行。試看後若專案版本已變更，必須重新載入及試看，避免覆蓋新內容。
- 確認套用會沿用原有儲存與核可失效規則；完成最終輸出的核可流程沒有改變。

## 本機實作與維護

`scripts/fx_preview_jobs.py` 管理專案專屬工作、候選設定、快取與取消；`scripts/fx_preview_render.py` 合成可播放 MP4；`scripts/fx_overlay.py` 與 `edit-style-profiles/tools/compose.py` 共用嚴格素材模式。

HTTP 入口為 `POST /api/fx-previews`，另有工作狀態、取消與確認端點。候選請求必須包含目前 `expected_revision`。確認透過專案鎖與版本比對寫入時間軸，試看本身只寫入 `working/fx-preview/`。

快取上限為 32 個 MP4／512 MiB（包含渲染中間檔），閒置保留最長 24 小時；工作狀態保留 30 分鐘。關閉或取消會終止所屬渲染程序群組。

驗證入口：`tests/test_fx_preview_api.py`、`tests/test_fx_preview_render.py`、`tests/test_fx_preview_browser.py`。真實影片與介面驗收仍須區分於使用假渲染器的 API 測試。
