# 在自己的影片上試看風格

1. 匯入影片後，按「試看本片特效」或新增特效圖層。
2. 選擇風格，分別設定「套用範圍」與範圍內的「試看片段」，再調整文字、擺位、色組和字型。
3. 用左右播放器比較原片與效果。需要檢查字幕、其他圖層及模板時，切到完整合成模式。
4. 等待短片生成並播放檢查，按「套用到時間軸」才會新增或替換圖層；取消試看不會套用候選設定。

卡片是風格示意圖。選取後的播放器才是用目前專案原片產生的動態結果。首次生成需要本機渲染，相同來源與設定可重用快取；快速切換設定會取消舊工作。

## 範圍

- 168 種風格可用此流程。B1 必須先從目前專案素材選擇照片或影片；沒有素材時不會拿原片冒充補畫面。請先透過素材區匯入，僅手動放進資料夾的檔案不會列為 B1 可選素材。
- 每次試看 0.1–4 秒，使用原片時間軸與 9:16 畫布。原片可以是橫向影片，構圖沿用專案的完整顯示或填滿設定。
- 單一特效模式適合快速比較風格；完整合成模式依目前時間軸納入其他圖層、字幕、模板及剪輯。跨過刪除片段時，試看影片會縮短，左右播放器依剪輯映射同步。
- 人物合成與 P5 聚光燈需要本片的有效人物遮罩；找不到清楚人物時會提示換片段，不會以示範人物代替。小、暗或不完整的人物可能被拒絕；燒在原片裡的字幕也可能影響去背。
- 試看長度不會縮短套用範圍。例如原效果長 8 秒、試看其中 2 秒，確認後仍保留 8 秒；只有修改套用範圍才會改變圖層起訖。渲染保留整段動畫相位，因此長效果的短試看仍可能需要較長準備時間。
- P5 可在原片畫面點選追蹤主體，也可回到自動選擇。多人交疊、離開畫面或遮罩不足時，應換時窗或重新選擇；選點不是跨遮擋的人物身分辨識。
- 文字自適應嘗試將溢出的文字換行或縮小。安全區、文字溢出與人物遮蔽提示是審片輔助；缺少可靠量測會明示，不能當成畫面品質已通過。
- 短預覽與整片輸出不能在同一專案同時執行。試看後若專案版本已變更，必須重新載入及試看，避免覆蓋新內容。
- 確認套用會沿用原有儲存與核可失效規則；完成最終輸出的核可流程沒有改變。

## 選擇與草稿

星號可收藏風格，也可切換最近使用的清單。收藏與草稿存在目前瀏覽器的本機儲存空間；清除網站資料後會消失。

未套用的候選依專案及替換圖層分開保存，關閉視窗或重新整理後仍可接續。專案版本已改變時會提示還原或丟棄草稿，還原不會直接套用，也不會繞過版本比對。

選擇快速版時，先顯示快速結果，再背景產生清晰版。升級期間可繼續看已完成的快速版；取消或失敗會保留畫面並顯示狀態，套用仍須等目前候選的清晰版完成。首次渲染速度依片長、效果、去背與電腦負載而異。單一效果模式的相同視覺設定可重用快取，包括確認新增後再開啟替換；完整合成的快取還會檢查其他圖層、字幕與剪輯內容。

## 本機實作與維護

`scripts/fx_preview_jobs.py` 管理專案專屬工作、候選設定、快取與取消；`scripts/fx_preview_contract.py` 驗證時窗與素材；`scripts/fx_preview_render.py` 合成可播放 MP4；`scripts/fx_overlay.py` 與 `edit-style-profiles/tools/compose.py` 共用嚴格素材模式。

HTTP 入口為 `POST /api/fx-previews`，另有工作狀態、取消與確認端點。候選請求必須包含目前 `expected_revision`。確認透過專案鎖與版本比對寫入時間軸，試看本身只寫入 `working/fx-preview/`。

Schema v1 保留相容：`candidate.window` 是最多 4 秒的試看片段；新增 `candidate.apply_window` 是實際套用範圍，未提供時沿用 window。`preview_options` 指定 single/timeline 與 draft/standard。素材只能提交 `asset_id + sha256`，由伺服器解析專案內來源；不接受用戶端路徑。

完整合成使用凍結快照與隔離工作副本；來源、素材、字型、其他圖層及渲染程式的相依變動都必須使舊結果失效。回傳的 `render_duration_s` 與 `time_map` 對應實際播放媒體，升級排隊時仍須保留舊媒體自己的時間映射。

人臉位置檢查使用隨技能附帶的 YuNet ONNX，來源為 [OpenCV Zoo 固定版本](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_detection_yunet)，採 MIT 授權。模型、授權與來源雜湊存於 `assets/models/yunet/`；執行時核對雜湊，不下載模型，也不傳送影片。這只找臉的位置，沒有辨識人物身分。

快取上限為 32 個 MP4／512 MiB（包含渲染中間檔），閒置保留最長 24 小時；工作狀態保留 30 分鐘。關閉或取消會終止所屬渲染程序群組。

驗證入口：`tests/test_fx_preview_api.py`、`tests/test_fx_preview_render.py`、`tests/test_fx_preview_browser.py`、`tests/test_fx_preview_preferences_browser.py` 與文字／追蹤測試。真實影片與介面驗收仍須區分於使用假渲染器的 API 測試；全風格覆蓋必須保留實際 MP4 與抽幀證據。
